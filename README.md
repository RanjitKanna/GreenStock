# Flutter Stock Portfolio App

A Flutter application to track stock prices, manage a portfolio, and visualize performance using charts.

---

## 🚀 Features

 Track stock prices

 Manage portfolio

 View stock price charts

 Local data storage

 Smooth animations and modern UI

---

## 📦 Packages Used

**💾 Local Storage**

 hive / hive_flutter  
 Stores portfolio data locally.

**⚙️ Dependency Injection**

 get_it  
 Service locator for dependency injection.

**🌐 Networking**

 dio  
 Fetches stock data from APIs.

**📊 Charts**

 fl_chart  
 Displays stock price charts and portfolio graphs.

**🎨 UI**

 google_fonts  
 Custom fonts

 skeletonizer  
 Loading skeleton UI

 percent_indicator  
 Portfolio percentage indicator

**✨ Animations**

 animations  
 Page transitions

 flutter_animate  
 UI animations

 lottie  
 JSON animations

**🧰 Utilities**

 intl  
 Date and currency formatting

 dartz  
 Functional error handling

**🔁 State Management**

 flutter_bloc  
 State management

 equatable  
 State comparison

 rxdart  
 Stream utilities

**📱 Responsiveness**

 flutter_screenutil  
 Responsive UI scaling
